# POND Chat acceptable use

Last updated: 29 October 2026

By using POND Chat with POND's server you agree to these rules. There is no tolerance for objectionable
content or abusive users.

## Don't post

- Anything illegal, including content that sexualises minors.
- Harassment, threats, hate speech or bullying.
- Sexually explicit or graphic violent content.
- Spam, scams or malware.
- Other people's private information without their consent.

## What we do

Anyone can report a message (long-press → Report content) or block a user (their profile → Block user). We review reports
within 24 hours, remove content that breaks these rules and remove the accounts that post it.
